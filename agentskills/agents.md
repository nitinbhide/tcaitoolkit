# Thinking Craftsman Agent Instructions

**About**
This AGENTS.md file is developed by Nitin Bhide (Thinking Craftsman). Use this file as reference to add instructions in your project on how to use various Thinking Craftsman Agentic Engineering skills

## General Behavior

- Prefer small, focused changes over large refactors
- Do not change public APIs unless explicitly instructed
- Preserve existing behavior unless the task explicitly says otherwise
- Follow existing patterns before introducing new ones
# Things You Must NOT Do

- Do not rewrite large portions of the codebase unless asked
- Do not change formatting across unrelated files
- Do not remove TODOs or comments without addressing them
- Do not assume undocumented behavior is safe to change
## When Unsure

- Prefer asking for clarification over guessing
- Explain trade-offs briefly in comments or PR descriptions
