# Thinking Craftsman Cookie Cutter for Agentic Engineering based Software Development project

This is `Cookie Cutter` to create default project structure following the Agentic Engineering principles for software development. 

It creates following

1. Recommended folder structure
2. AGENTS.md file
3. Recommended set of files like specification index, Architecture, ADR (Architecture Decision Records) etc

It does not assume any particular 'coding agent'
